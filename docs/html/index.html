CacheControl — система управления страничным кэшем

CacheControl — это фоновый демон, который следит за заданными файлами или каталогами и управляет их присутствием в оперативной памяти (page cache). Демон может принудительно подгружать файлы в кэш для ускорения доступа (например, перед запуском тяжёлого приложения) или выгружать малоиспользуемые файлы, освобождая память.

Возможности

  • Три политики кэширования:
    • keep — постоянно держать файл(ы) в кэше
    • evict — выгружать, если файл не использовался заданное время
    • monitor — только собирать статистику, не вмешиваясь
  • Работа с масками — поддержка шаблонов в путях к файлам (/var/log/*.log)
  • Мониторинг страничного кэша — использование системного вызова mincore() для анализа присутствия страниц в памяти
  • Отслеживание изменений — мониторинг файлов через inotify (события: изменение, удаление, перемещение)
  • Управление через очередь сообщений — POSIX очередь для отправки команд демону
  • Обработка сигналов — корректное завершение, перезагрузка конфигурации, отладочный вывод статистики
  • Логирование — все события и ошибки направляются в syslog

Требования

  • Компилятор GCC/Clang с поддержкой C11
  • POSIX-совместимая ОС (Linux)

Конфигурация

Формат конфигурационного файла

<путь_с_маской> <политика> [параметры]

Поддерживаемые политики

Политика Описание
keep Постоянно держать файл(ы) в кэше (периодически подгружать при необходимости)
evict Выгружать из кэша, если файл не использовался в течение заданного времени
monitor Только собирать статистику, не вмешиваясь

Параметры

  • age=<секунды> — время в секундах, после которого файл будет выгружен (для политики evict)
  • interval=<секунды> — интервал сканирования (по умолчанию 60 секунд)

Пример конфигурационного файла

Файл /etc/cachecontrol.conf:

# База данных MySQL — всегда в кэше
/var/lib/mysql/* keep
# Логи выгружаются через час
/var/log/*.log evict age=3600
# Временные файлы выгружаются через 5 минут
/tmp/* evict age=300
# Файлы данных — только мониторинг
/opt/data/*.dat monitor
# Интервал сканирования
interval=120

Уровни логирования

Все сообщения демона записываются в syslog.

Уровень Назначение
LOG_INFO Информационные сообщения
LOG_WARNING Предупреждения
LOG_ERR Критические ошибки

Использование

Запуск демона

# Запуск с конфигом по умолчанию (/etc/cachecontrol.conf)
./bin/cache_control -d
# Запуск с указанием конфигурационного файла
./bin/cache_control -c /etc/cachecontrol.conf

Запуск медиатора

# Интерактивный режим управления демоном
./bin/cache_control_mediator

Команды медиатора

Команда Аргумент Описание
status all Вывести статистику по файлу или по всем отслеживаемым
cache <file> Принудительно подгрузить файл в кэш (игнорируя политику)
evict <file> Принудительно выгрузить файл из кэша
reload — Перечитать конфигурационный файл без остановки
exit — Корректно завершить работу демона
clear — Очистить терминал

Сигналы

Демон поддерживает обработку следующих сигналов:

Сигнал Действие
SIGTERM / SIGINT Корректное завершение работы (освобождение памяти, закрытие дескрипторов, удаление PID-файла)
SIGHUP Перезагрузка конфигурационного файла без остановки демона
SIGUSR1 Вывод текущей статистики в syslog (для отладки)

Пример отправки сигналов:

# Перезагрузить конфигурацию
kill -SIGHUP <PID>
# Вывести статистику в syslog
kill -SIGUSR1 <PID>
# Завершить демон
kill <PID>
kill -SIGINT <PID>
